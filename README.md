# CT2-nx

A native Nintendo Switch (and PC) port of **Crazy Taxi 2** for the Sega Dreamcast (USA), made by
static recompilation with [dream-recomp](https://github.com/phobos665/dream-recomp). The sister
project of [CTDC-nx](https://github.com/FurryLilManChild/CTDC-nx) (Crazy Taxi).

Work in progress: nothing to download yet. No game data is included; you need your own disc
dump.

endorsed by Sega.
